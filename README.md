# 보험 상품 보험료·보장 비교 대시보드

생명보험협회·손해보험협회 공시실의 **상품비교공시**를 매주 자동 수집해, 같은 표준조건에서 회사별 보험료·보험가격지수·담보 구성을 비교합니다.

| 부품 | 역할 | 위치 |
|---|---|---|
| 수집 로봇 | 협회 공시 → Supabase 적재 (매주 월 07:17) | `collector/collect.py`, `.github/workflows/collect.yml` |
| 창고 | Supabase 표 `ins_*` | `collector/schema.sql` |
| 화면 | 대시보드 (예정) | `index.html` |

## 데이터 출처
- 손해보험협회 공시실 상품비교공시(장기보장성): https://kpub.knia.or.kr
- 생명보험협회 공시실 상품비교공시(보장성): https://pub.insure.or.kr

## 한계
- 공시 보험료는 협회 표준조건(주로 40세) 기준이며 실제 가입 보험료와 다릅니다.
- 생보는 주계약 보험료, 손보는 표준 담보 구성의 보장보험료라 **절대 보험료보다 보험가격지수로 비교**해야 공정합니다.
- 회사마다 담보 명칭이 달라 담보그룹 분류 규칙으로 통일합니다(작업 중).
